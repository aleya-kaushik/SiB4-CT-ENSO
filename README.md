# ENSO Terrestrial Carbon Response Scorecard

GitHub Pages test build for the CONUS NOAA climate-region prototype.

## Publish with GitHub Pages
1. Create a public repository (for example `enso-terrestrial-carbon-dashboard`).
2. Upload `index.html` to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, choose the default branch and `/ (root)`, then save.
4. Open the Pages URL in an incognito/private browser window to confirm that it is publicly viewable.

This version is self-contained: all data and plotting code are embedded in `index.html`; no CSV or Python files are required by the viewer.
